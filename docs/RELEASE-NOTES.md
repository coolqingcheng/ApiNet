ApiNet 0.1.17：修复 Windows 任务栏继续显示旧图标的问题。

- 快捷方式改用按图标内容生成独立路径的 ICO 文件，避免 Windows 继续复用 EXE 路径对应的旧图标缓存。
- 安装、覆盖修复和每次启动时，检查并更新指向当前安装的桌面、开始菜单及任务栏固定快捷方式，通知 Windows 刷新。
- 保留快捷方式的目标、启动参数、应用标识和名称；重命名的任务栏快捷方式也可修复。修复失败的快捷方式会在后续启动时重试。
- 保留双向数据流图标及发送按钮文字、加载动画居中效果。

Windows Setup.exe 支持覆盖安装和同版本修复。Windows x64、Linux x64、macOS ARM64 均提供 Native AOT 包，在线更新继续使用公开 GitHub Releases；`*.nupkg` 和 `releases.*.json` 用于更新，SHA256SUMS.txt 提供校验。

更新说明展示功能自 0.1.11 客户端起生效；更早版本需要先升级，后续升级提示即可显示更新内容。
