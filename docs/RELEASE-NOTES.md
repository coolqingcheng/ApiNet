ApiNet 0.1.14：统一工作台样式，新增午夜蓝主题和响应头表格。

- 提供深色、浅色、午夜蓝三套 VS Code 风格配色；侧栏按钮依次切换，也可在设置中直接选择，保存后下次启动继续使用。
- 统一输入框、按钮、下拉框、标签和面板的圆角、边框及焦点色，缩小顶部栏、侧栏、工具页和请求编辑区的间距。
- Query、Headers、表单和 WebSocket 参数共用紧凑的 KEY / VALUE / DESCRIPTION 表格，使用统一表头、细分隔线和悬停效果；保留空行新增、文件上传、批量编辑和键盘导航。
- 美化所有勾选框的选中、未选中、半选、禁用与键盘焦点状态；参数表头部分选中时，点击会全部启用，再次点击则全部停用。
- 响应 Headers 默认以 KEY / VALUE 表格展示，支持切换纯文本、选择复制和长值换行；保留字段顺序、重复字段及原始文本，新响应和历史回看均更新显示，每个请求独立切换视图。
- 调整请求和响应的默认区域比例，让小窗口也能查看更多响应内容，仍支持拖动分隔条改变高度。

Windows Setup.exe 支持覆盖安装和同版本修复。Windows x64、Linux x64、macOS ARM64 均提供 Native AOT 包，在线更新继续使用公开 GitHub Releases；`*.nupkg` 和 `releases.*.json` 用于更新，SHA256SUMS.txt 提供校验。

更新说明展示功能自 0.1.11 客户端起生效；更早版本需要先升级，后续升级提示即可显示更新内容。
