ApiNet 0.1.13：响应文本支持格式化与压缩，优化大 JSON 处理。

- 响应 Body 增加格式化、压缩和原文操作，支持 JSON、XML、HTML、JavaScript、CSS；可手动切换类型，修正接口返回的错误 Content-Type。
- 格式化只调整当前显示，原始下载文件、历史记录和请求正文保持不变；无效内容保留原文并显示错误，纯文本不进行破坏性的空白删除。
- JSON 工具改为后台处理，显示处理中状态并支持取消；修改输入、切换工具或收到新响应时，旧任务不会覆盖新结果。
- JSON 使用逐 token 读写，避免构建整份 DOM 和额外输出缓冲复制，保留大整数精度、数字写法和字符串内容。
- 超过约 100 万字符的大文本跳过语法着色；超长单行只读取高亮范围内的前缀，减少粘贴、滚动和渲染时的分配。
- 保留响应自动换行、时间戳 / Cron 工具、对齐后的状态栏和更新旋转圆圈。

Windows Setup.exe 支持覆盖安装和同版本修复。Windows x64、Linux x64、macOS ARM64 均提供 Native AOT 包，在线更新继续使用公开 GitHub Releases；`*.nupkg` 和 `releases.*.json` 用于更新，SHA256SUMS.txt 提供校验。

更新说明展示功能自 0.1.11 客户端起生效；更早版本需要先升级，后续升级提示即可显示更新内容。
