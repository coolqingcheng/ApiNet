ApiNet 0.1.8：请求标签支持批量关闭。

- 请求标签右键菜单新增“关闭其他标签”“关闭左侧标签”“关闭右侧标签”和“全部关闭”，以右键点击的标签及当前排列为准，适用于 HTTP 和 WebSocket。
- 没有可关闭标签时对应菜单置灰；关闭后保留有效的当前标签，全部关闭后显示空白工作台，集合中的请求仍然保留。
- 批量关闭沿用未保存修改的保存/放弃/取消和 WebSocket 断开确认，取消或保存失败后停止后续关闭；关闭操作进行中禁用其他关闭入口，避免重复确认及重复释放连接。
- 关闭后的标签列表同步保存到本地，全部标签搜索列表实时更新。

Windows Setup.exe 支持覆盖安装和同版本修复。Windows、Linux、macOS 均提供 x64 / ARM64 Native AOT 包，在线更新继续使用公开 GitHub Releases；`*.nupkg` 和 `releases.*.json` 用于更新，SHA256SUMS.txt 提供校验。
