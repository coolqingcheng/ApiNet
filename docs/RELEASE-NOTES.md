ApiNet 0.1.12：新增时间戳和 Cron 工具，调整底部状态栏。

- 工具新增时间戳 / 日期双向转换，明确选择秒或毫秒，支持当前时间、本地时区、UTC 和带偏移的 ISO 8601 日期；同时展示秒、毫秒及本地 / UTC 结果。
- 工具新增 Cron 解析与生成，支持 5 段和含秒的 6 段表达式、字段说明、常用模板、自定义字段以及接下来 10 次执行时间；可选择本地时区或 UTC。
- Cron 使用 Cronos 规则：周日为 0 或 7，日期与星期同时指定时需同时满足，不含年份；仅提供预览，不会执行任务。
- 底部状态栏统一版本、工作区、更新和代理文字的字号、行高与垂直对齐，修复按钮高度挤压导致的错位。
- 检查和下载更新时改为小圆圈旋转，完成或失败后自动隐藏；保留更新内容和安装入口。
- HTTP 响应正文（JSON、XML、HTML、普通文本等）和响应头默认自动换行，随面板宽度调整显示，保留原始内容、语法高亮和复制 / 保存结果。
- 包含参数表格 KEY / VALUE 输入崩溃修复，以及省略 HTTP 协议时自动补全地址的改进。

Windows Setup.exe 支持覆盖安装和同版本修复。Windows x64、Linux x64、macOS ARM64 均提供 Native AOT 包，在线更新继续使用公开 GitHub Releases；`*.nupkg` 和 `releases.*.json` 用于更新，SHA256SUMS.txt 提供校验。

更新说明展示功能自 0.1.11 客户端起生效；更早版本需要先升级，后续升级提示即可显示更新内容。
