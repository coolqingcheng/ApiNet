ApiNet 0.1.11：升级提示支持查看更新内容。

- 升级提示在目标版本号下显示更新内容，保留立即升级、退出时升级和稍后三个选项。
- 较长说明支持滚动、选择和复制，升级按钮保持可见；稍后从底部“安装更新”重新打开时仍可查看该版本说明。
- GitHub 发布页、安装包和在线更新索引使用同一份更新说明；没有说明的旧包显示“此版本未提供更新说明”，仍可正常升级。
- 再次检查更新不会隐藏已下载更新的安装入口。
- 包含 0.1.10 的参数表格 KEY / VALUE 输入崩溃修复，以及省略 HTTP 协议时自动补全地址的改进。

Windows Setup.exe 支持覆盖安装和同版本修复。Windows x64、Linux x64、macOS ARM64 均提供 Native AOT 包，在线更新继续使用公开 GitHub Releases；`*.nupkg` 和 `releases.*.json` 用于更新，SHA256SUMS.txt 提供校验。

更新说明展示功能自 0.1.11 客户端起生效；更早版本需要先升级，后续升级提示即可显示更新内容。
